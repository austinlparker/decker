# Block fonts

FIGlet fonts used for titles and impact lines. Downloaded from
[xero/figlet-fonts](https://github.com/xero/figlet-fonts), a widely used
collection.

| File | Notes from the file header |
| --- | --- |
| ANSI Shadow.flf | Converted from a TheDraw font with patorjk's FIGfont editor; author unknown |
| ANSI Regular.flf | Converted from a TheDraw font with patorjk's FIGfont editor; author unknown |
| Calvin S.flf | Converted from a TheDraw font with patorjk's FIGfont editor; author unknown |
| DOS Rebel.flf | "Rebel" by Valerie Mates, based on a font by Ron Bliss (1994) |
| Delta Corps Priest 1.flf | By CoSMiC cHiLD; converted with patorjk's FIGfont editor |

None of these files states a license. FIGlet fonts like these have been
freely redistributed for decades, but if you publish this deck, check that
you're comfortable with that.
